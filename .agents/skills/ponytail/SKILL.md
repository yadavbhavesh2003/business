# Ponytail — Minimalist Code Discipline

## Principles
1. Solve today's concrete problem with the minimum necessary code.
2. No speculative abstractions, premature generalizations, or unused helper wrappers.
3. Zero unnecessary third-party dependencies when Node.js standard libraries or existing utilities suffice.
4. Keep functions small, single-purpose, and easily testable.
