# Hallmark — Anti-AI-Slop Gate

## Design System Invariants
1. No unprompted neon glows, purple gradients, or generic AI aesthetic tropes.
2. Maintain WCAG AA contrast (minimum 4.5:1 for body copy).
3. Back-office ERP tables must be compact, dense, and left-aligned, not centered landing page cards.
4. Theme coherence: Client App uses Light canvas (#F6F7F5) with emerald accents (#0F766E). Platform Admin uses Midnight slate (#0F172A) with indigo accents (#6366F1).
