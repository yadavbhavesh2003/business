# Thermal Printing & Barcode Hardware Driver

## Hardware Capabilities
1. 58mm (32-column) and 80mm (48-column) monospaced receipt formatting.
2. Dynamic NPCI UPI QR code byte raster generation.
3. Native paper cut byte sequences (GS V 66 0).
4. High-speed USB/Bluetooth HID barcode scanner keystroke parser.
