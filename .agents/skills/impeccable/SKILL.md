# Impeccable — Frontend Precision & Spacing Rhythm

## Layout Guidelines
1. Use standard 4px/8px spacing steps (4, 8, 12, 16, 20, 24, 32px).
2. Numerical amounts and meter counts must use font-variant-numeric: tabular-nums and be right-aligned.
3. Mobile touch targets must measure at least 44px in height.
4. Gujarati matras must never clip: enforce line-height 1.5 to 1.6 on all bilingual elements.
